# SolveLens

数学・物理の問題を写真で送り、答え・途中式・考え方・検算をAIに説明してもらうサイトです。スマートフォンのカメラから直接撮影できます。

## 必要なもの

- Node.js 20以上が動くサーバー
- OpenAI APIキー（ChatGPT Plusとは別に、API利用料がかかります）

## 動かし方

1. ZIPを展開します。
2. `.env.example`をコピーして、ファイル名を`.env`にします。
3. `.env`の`OPENAI_API_KEY=`の右側に、自分のAPIキーを入力します。
4. サーバー側の環境変数として同じ内容を設定し、`npm start`を実行します。
5. 表示されたURLをブラウザで開きます。

このプロジェクトは追加ライブラリなしで動きます。Render、Railway、Replitなど、Node.js 20以上と環境変数を設定できるサービスに設置できます。

## 大切な注意

- APIキーは絶対に`public`フォルダや画面上の入力欄へ書かないでください。
- `.env`は他人に送ったり、公開場所へアップロードしたりしないでください。
- AIの解説は誤る場合があります。提出前に教科書や先生の説明でも確認してください。
- 問題画像はこのアプリでは保存しませんが、解説作成のためOpenAI APIへ送信されます。

## 設定

- `OPENAI_MODEL`: 使用する画像対応モデル名（初期値は`gpt-5.5`）
- `PORT`: サーバーのポート番号（初期値は`3000`）
